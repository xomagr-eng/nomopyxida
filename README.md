# ΝΟΜΟΠΥΞΙΔΑ 360°

Offline νομικός οδηγός & βάση ελληνικής νομοθεσίας (Σύνταγμα, αστικό, ποινικό, εργατικό,
οικογενειακό, καταναλωτικό, μισθώσεις, ΚΟΚ, διοικητικό, φορολογικό, τραπεζικά, ασφαλιστικό,
τελωνειακό/ενωσιακό ΕΕ) με έξυπνη αναζήτηση, σύμβουλο «έχω ένα πρόβλημα», πρότυπα εγγράφων,
πηγές δικαίου με ΦΕΚ & deep-links σε επίσημες πηγές (EUR-Lex, kodiko, elib ΑΑΔΕ, ΝΣΚ).

**PWA** — εγκαθίσταται στο κινητό/PC και δουλεύει offline.

- Εφαρμογή: `index.html` (PWA)
- Αυτόνομη έκδοση (ένα αρχείο): `NOMOPYXIDA360.html`
- ZIP για hosting: `NOMOPYXIDA360.zip`

Ενημερωτικό υλικό — δεν υποκαθιστά τη νομική συμβουλή.
